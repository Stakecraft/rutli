# Quality report: v0.4.0 → main, November 2026

How the code changed between the v0.4.0 release (`ebab88b`, tagged 2026-11-14) and `main` on
2026-11-19 (`ffedb4d`). Both trees were measured in CI on the same day with the same pinned tools
and the same Rust toolchain (1.100.0): `scripts/quality-report.sh v0.4.0 origin/main` in the
Quality workflow. Every metric has a value for both sides; nothing below is estimated.

## In short

- **Supply chain and CI hardening is the big change.** zizmor findings on the workflows fell from
  34 to 2 and Semgrep warnings from 51 to 13, almost all of it from pinning every action to a
  commit (#107). `cargo deny` went from 9 errors to 0 (the heapless advisories triaged, #111) and
  `cargo audit` warnings from 12 to 11. No known vulnerabilities in the Rust lock file on either
  side.
- **Rust: slightly more tested, otherwise steady.** 12 more tests (512 → 524), line coverage
  88.22% → 88.39%, function coverage 86.33% → 86.60%. Still zero default clippy warnings, zero
  `unwrap()` in non-test code, 47 unchecked index operations, and the same 30 unsafe expressions
  (all in `rutli-cosigner`).
- **One gated metric got worse:** the rustqual score, 61.65% → 60.91%, mostly duplication (DRY
  88.74% → 87.71%) in the code added since the release. `clippy::pedantic` warnings grew by 11
  (1,110 → 1,121); they are reported, not gated.
- **Scala driver, shell, Python, Dockerfiles, Helm/k8s, protobuf, gitleaks, typos: unchanged.**
  The driver has 201 tests, no compiler warnings and 76.68% statement coverage on both sides.
- **Old debt, now counted:** 73 Rust files differ from `rustfmt`, 26 Scala files from the new
  `.scalafmt.conf`, 17 shell scripts from `shfmt`; 65 `buf lint` findings; 62 kube-linter
  findings; 7 gitleaks findings (test strings, a public key and a doc comment; no secrets) and 44 `typos` findings. From now
  on none of these may grow.
- **Released image (not part of the tree comparison):** trivy finds 0 critical, 12 high, 51
  medium and 36 low vulnerabilities in `ghcr.io/stakecraft/rutli-cosigner:0.4.0` (scan of
  2026-11-19). CI scans it nightly from now on.
