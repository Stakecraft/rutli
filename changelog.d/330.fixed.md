- **Every store directory the cosigner creates has its parent synced before use.** This covers the nonce marker directories, the journal root and each per-key journal directory, and every level created along with them. If that sync fails, the directories this call created are removed and the error is returned, so the next attempt creates and syncs them again. A directory that already exists is not synced. The cosigner now needs read permission on the parent of these directories when it creates them.
