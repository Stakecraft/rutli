- **The nonce store and the sign journal sync the parent of their directory on the first successful open in each process.** Before, only the per-key journal directory synced its parent, and only when it had just been created; the nonce store and the journal root did not. A failed sync, or a process that stopped before it, was not retried on the next open. Now a directory that already exists has its parent synced on its first successful open in each process, and a newly created directory, with every level created along with it, always syncs its parent, even if the same path was synced before. An error from the sync is returned, and a failed sync is retried on the next open. The cosigner now needs read permission on the parent of the journal directory and of each `*.nonces` directory.
