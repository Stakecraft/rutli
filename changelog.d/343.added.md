- **Cosigners on plain Linux hosts** (`docs/bare-metal.md`): systemd units in `deploy/systemd/` and
  an Ansible role in `deploy/ansible/`, for Debian 12/13 and Ubuntu 24.04. The service runs as its
  own user with a read-only file system, no capabilities, no swap and `/tmp` in memory; the seal
  bundle and the TLS key stay root-only on disk and reach the daemon as systemd credentials. The
  role installs one cosigner per host, checks the new config with `check-config` before it
  replaces the old one, and upgrades one host at a time. It creates no key material and runs no
  ceremony; under the production profile it takes no secret from the control machine. Backups run
  from two timers with the same content and log lines as the chart's sidecar. The firewall rules
  are an example only. Lab first: a full install on three hosts has not been recorded yet. No
  change to the cosigner or the driver.
