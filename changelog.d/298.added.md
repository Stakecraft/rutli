- **Helm chart: a per-node `nodeSelector`.** `nodes[].nodeSelector` is merged over the global `nodeSelector` for that cosigner only, so each cosigner can be placed on its own site. Set it before the first install: a volume bound in one zone keeps its pod there.
- **Cluster suite: the cosigners' placement is fixed and recorded.** The deploy pins cosigner `<id>` to a node labelled `rutli-perf/cosigner=<id>`; `cluster.json` records each cosigner's node and zone, and `compare.py` does not compare the latency of runs whose cosigners were placed differently.
