- **The release assets check caches sbt and the driver's dependencies.** It failed on a pull request
  because the sbt launcher could not download sbt itself (Maven Central answered HTTP 429 for 17
  minutes); it now restores them from the cache that `setup-java` keeps, as the unit-test job does.
  The release build still uses no cache; `docs/releasing.md` says that a 429 there fails before
  anything is signed and the failed jobs can be re-run.
