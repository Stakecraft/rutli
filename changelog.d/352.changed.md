- **The production profile requires the refresh interval.** Under `profile: production` a cosigner
  now refuses to start, and `check-config` lists a required finding, when
  `signing_policy.refresh_min_interval_secs` is `0` (off) or less than 259200 (72 h, the default).
  Before, a production node started with the interval turned off and only warned. Under `lab` the
  finding is logged and nothing is refused. `refresh_interval_waived_at`, the incident path for one
  refresh inside the interval, is unchanged. Upgrade note: a `production` config written for
  0.5.0-rc.1 that sets the key below 259200 must remove it or raise it; a config that does not set
  it needs no change.
