Rütli FROST cosigner cluster ({{ .Chart.AppVersion }})

Image: {{ include "rutli-cosigner.image" . }}
Replicas: {{ .Values.replicaCount }}  threshold: {{ .Values.threshold }}

BEFORE the pods can start you must create secrets in this namespace:

  1) mTLS material ({{ if eq .Values.tls.layout "perNode" }}the CA + one Secret per cosigner{{ else }}legacy single Secret{{ end }}):
{{- if eq .Values.tls.layout "perNode" }}
     kubectl -n {{ .Release.Namespace }} create secret generic {{ .Values.tls.caSecretName }} --from-file=ca.crt=certs/ca.crt
{{- range $i := until (int .Values.replicaCount) }}
     kubectl -n {{ $.Release.Namespace }} create secret tls {{ $.Values.tls.perNodeSecretPrefix }}{{ add $i 1 }} --cert=certs/cosigner{{ add $i 1 }}.crt --key=certs/cosigner{{ add $i 1 }}.key
{{- end }}
{{- else }}
     kubectl -n {{ .Release.Namespace }} create secret generic {{ .Values.tlsSecretName }} \
       --from-file=ca.crt=certs/ca.crt \
       --from-file=cosigner1.crt=certs/cosigner1.crt --from-file=cosigner1.key=certs/cosigner1.key \
       # … repeat for each cosigner …
{{- end }}
     Each cosigner container sees only its own key (init container tls-select); see README.

  2) Seal master secret (≥ 32 chars):
     kubectl -n {{ .Release.Namespace }} create secret generic {{ .Values.sealSecretName }} \
       --from-literal={{ .Values.sealSecretKey }}="$(openssl rand -hex 32)"

Generate certs with:  scripts/gen-frost-certs.sh {{ .Values.replicaCount }} ./certs

Canton driver endpoints (headless):
{{- $fullname := include "rutli-cosigner.fullname" . }}
{{- $port := .Values.service.grpcPort }}
{{- range $i := until (int .Values.replicaCount) }}
  - {{ $fullname }}-{{ $i }}.{{ $fullname }}.{{ $.Release.Namespace }}.svc.cluster.local:{{ $port }}
{{- end }}

Label the Canton namespace {{ .Values.networkPolicy.clientNamespaceLabel }}=true and the
participant pod {{ .Values.networkPolicy.clientPodLabel }}=true so NetworkPolicy allows the driver.

{{- if .Values.backup.enabled }}

Backups: CronJob {{ include "rutli-cosigner.backup.name" . }} ({{ .Values.backup.schedule }}) runs
`rutli-cosigner backup` INSIDE each cosigner via kubectl exec and hands the tars to backup.ship.
The Job FAILS until backup.ship names an off-cluster destination.
{{- else }}

Backups are OFF (backup.enabled=false). Enable them before go-live. Never mount a cosigner volume
into another pod to take one — the chart's backup runs inside the cosigner (README, "Backups").
{{- end }}
